## 🚀 HƯỚNG DẪN ĐƯA LÊN GITHUB & SỬ DỤNG MIỄN PHÍ

### Cách 1: Sử dụng GitHub Pages (Miễn phí 100%)
1. Tạo một repository mới trên GitHub (ví dụ: `tra-loi-gt-pro`).
2. Mở Terminal và đẩy thư mục này lên GitHub:
   ```bash
   cd /Users/hatrungnhu/Downloads/tra_loi_gt_pro
   git init
   git add .
   git commit -m "feat: Tra Loi GT Pro complete legal database and TTKS engine"
   git branch -M main
   git remote add origin https://github.com/<tai-khoan-cua-ban>/tra-loi-gt-pro.git
   git push -u origin main
   ```
3. Vào repository trên GitHub $\rightarrow$ **Settings** $\rightarrow$ **Pages** $\rightarrow$ Tại mục **Build and deployment**, chọn **Branch: `main`** và thư mục **`/(root)`** $\rightarrow$ Bấm **Save**.
4. Sau 1 phút, bạn sẽ có link web trực tiếp dạng:  
   `https://<tai-khoan-cua-ban>.github.io/tra-loi-gt-pro/`

### Cách 2: Sử dụng Vercel (Khuyên dùng - Cực nhanh)

## ⚖️ CẤU TRÚC PHÁP LÝ & TÍNH NĂNG CHÍNH

1. **CSDL 475 hành vi vi phạm trọn vẹn từ Nghị định**:
   * Điều 6: Ô tô (Khoản 1a đến 16).
   * Điều 7: Mô tô, xe máy (Khoản 1 đến 13).
   * Điều 8: Xe máy chuyên dùng.
   * Điều 9: Xe đạp, xe thô sơ.
   * Điều 10 & 11: Người đi bộ & Vật nuôi.
   * Điều 12: Sử dụng lòng đường, vỉa hè.
   * Điều 13, 14, 16: Thiết bị an toàn & Đăng kiểm.
   * Điều 18: Điều kiện người lái ($\le 125\text{cc}$ vs $> 125\text{cc}$, ô tô, tuổi, giấy tờ).
   * Điều 20 & 21: Vận tải hành khách & Hàng hóa (quá tải, quá khổ).
   * Điều 32: Trách nhiệm Chủ phương tiện (Cá nhân vs Tổ chức).
   * Điều 48: Tạm giữ phương tiện và giấy tờ.
2. **Quy tắc Trừ điểm GPLX cao nhất (Điều 50.1.b)**.
3. **Quy tắc Tước GPLX ưu tiên (Điều 5.2 & Điều 50.1.đ)**.
4. **Chế độ TTKS & Lập Biên bản Vi phạm Hành chính (BBVPHC) nhanh chóng**.
